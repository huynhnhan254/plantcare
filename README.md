# PlantCare

PlantCare is a plant-care website project designed to help people discover plants, learn how to care for them, and get suggestions for common plant problems.

This project is being developed incrementally as a portfolio project to practice backend development, RESTful APIs, and frontend development.

## Planned Features

- Browse and search plants
- View plant details and available care information
- Ask an AI assistant questions about plant care
- Describe plant symptoms and receive possible explanations and care suggestions

## Tech Stack

**Backend**
- Java 21
- Spring Boot
- Maven
- Spring Web
- Bean Validation

**Frontend**
- HTML
- CSS
- JavaScript

**Planned Integrations**
- External plant information API
- Ollama for local AI assistance
